# eyeShell i18n 開發指南

eyeShell 使用 JDK 內建的 `ResourceBundle` 與 UTF-8 `.properties`，沒有額外依賴。所有查表都經過
`platform/I18n.kt`，UI 程式碼不得直接讀取 properties。

## 檔案位置

```
src/main/resources/i18n/
  messages.properties          # 英文（base，也是所有語言的 fallback）
  messages_zh_TW.properties    # 繁體中文
  messages_zh_CN.properties    # 简体中文
  messages_ja.properties       # 日本語
```

`messages.properties` 是**唯一權威清單**：其他語言檔必須有完全相同的 key。缺 key 的測試會失敗，
所以不會出現某個語言少一行而默默顯示英文的情況。

## 新增一種語言（例如韓文）

1. 複製 `messages.properties` 為 `messages_ko.properties`，只翻譯「值」，不要改 key。
2. 在 `I18n.SUPPORTED` 加入 `Locale.KOREAN`、`I18n.SUPPORTED_IDS` 加入 `"ko"`，
   並在 `I18n.normalize` 加上 `ko` 的判斷（若該語言不需要地區變體）。
3. 在 `SettingsController.LANGUAGE_OPTIONS` 加入一組 `LanguageOption("ko", "settings.language.ko")`。
4. 在四個既有語言檔都補上 `settings.language.ko=<該語言自稱>`（例如 `한국어`）。
5. 執行 `.\scripts\gradlew-local.ps1 test --tests "*I18nTest"` 確認 key 集合一致。

## key 命名規則

- `settings.<頁面>.<欄位>`：Settings 對話框。
- `settings.<頁面>.<欄位>.hint`：同一列的灰色提示。
- `workbench.*`：主工作台按鈕、狀態列、空狀態。
- `sessionStatus.*`：Session 狀態標籤；`sessionStatus.line.*` 給狀態列用的句子（可含 `{0}`）。
- `about.*` 若之後有更多 About 專用字串再開；目前沿用 `settings.about.*`。

## 參數與格式化

- 需要插值時使用 `I18n.t("key", arg0, arg1)`，底層是 `MessageFormat`。
- `MessageFormat` 會把單引號 `'` 當作跳脫字元；譯文請避免使用單引號，或寫成 `''`。
- 數字格式（例如對比度 `{0}`）已在呼叫端用 `Locale.ROOT` 格式化，避免小數點隨語言改變。

## 已知行為

- 啟動時依 `app.locale`（`system`／`en`／`zh-TW`／`zh-CN`／`ja`）載入；`system` 會讀作業系統 locale，
  未知語言一律回退英文，`zh` 無地區時預設繁體中文。
- **必須使用 `ResourceBundle.Control.getNoFallbackControl`**：預設 control 會在 base bundle 之前
  回退到 JVM 預設 locale，在 zh-TW 主機上會讓 `en` 變成中文。
- 切換語言會重建 Settings 對話框並立即生效；主視窗與其他面板目前需要重啟後才套用（
  已在 Settings 顯示提示），後續會逐一把剩餘面板接到同一份字典。
- 開發者診斷訊息（log、例外訊息）維持英文，不列入翻譯。

## 翻譯進度

已接線：Settings（General／Terminal／Colors／Background／About）、主工作台主要按鈕與狀態列、
Session 狀態標籤、Monitor 側欄、SFTP 面板、Commands 面板、主機與 SFTP 表格欄位與驗證方式、
終端右鍵選單、搜尋列、Highlight 對話框、SSH 連線對話框、Saved Host 編輯器／主機清單對話框、
Host Key 確認視窗，以及 `UiText` 的憑證提示。

新增字串時請同步更新四個語言檔，`I18nTest` 會檢查 key 集合一致。
